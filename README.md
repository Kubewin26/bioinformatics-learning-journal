# Bioinformatics Learning Journal

This repository documents my 6-month journey from biology graduate
to practical bioinformatician.

**Start date:** July 13, 2026
**Goal:** Take biological sequence data, process it, analyse it,
visualise it, explain the result, and share the workflow reproducibly.

## Background

I have a background in biology, biomedical sciences, and microbiology.
I am starting from zero coding experience.

## Week 1 — Bash and Linux Command Line (Jul 13–19)

- Set up WSL Ubuntu as my bioinformatics environment
- Learned core Bash commands: pwd, ls, cd, mkdir, touch, cp, mv, rm, cat, head, tail, wc
- Connected VS Code to WSL
- Created my workspace: ~/bioinformatics-roadmap
- Completed a mini-project inspecting a mock DNA FASTA file
- Created a Bash cheat sheet

## Week 2 — Git and GitHub (Jul 20–26)

- Learned the three-tree Git architecture
- Configured Git identity inside WSL
- Created this learning journal repository
- Learning to track, commit, and push work to GitHub

## Roadmap

Month 1: Bash, Git, Python basics
Month 2: Sequence bioinformatics, BLAST, Biopython, Rosalind
Month 3: NGS, FASTQ, quality control, alignment, variant calling
Month 4: Microbiome, 16S, QIIME 2
Month 5: R, statistics, RNA-seq, DESeq2
Month 6: Reproducibility, pipelines, capstone projects
