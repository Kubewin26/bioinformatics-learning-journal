What I learned:
- pwd shows my current location
- mkdir creates folders
- cd moves into folders
- ls lists files and folders
- touch creates an empty file
- nano is used to write inside an empty file after it is created using the touch command or it directly creates the empty file and open it if it has not been created before. 

I learned there is GUI, which is graphical user interface, and it is very common. 
It is easy and visual and involves users interacting with a computer mainly by clicking a mouse and using menu-driven interactions. However, it is poorly suited for complex tasks and is quite slow to get certain tasks done. That is where the CLI (Command Line Interface) comes into play. It makes automation of tasks easier and faster and involves reading and writing texts. 
The Shell is one such program that allows one to type and use commands to get tasks done. Bash is one of the Unix shell command languages that I will learn and need in my bioinformatics journey so I need to master it. 
Shell commands can be put together to make a script that can be run subsequently to automate tasks.
