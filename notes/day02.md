# Day 2 - Directory Navigation

Date: July 14, 2026

Today I practiced moving around the Linux file system using Bash commands.

Commands practiced:
- pwd
- ls
- cd
- cd ..
- cd ~
- cd /
- ls -a
- ls -l

What I learned:
- pwd shows my current working directory.
- cd moves me into another specified directory.
- cd .. moves me one level up.
- cd ~ takes me back to my home directory.
- An absolute path starts from /.
- A relative path starts from my current location.
- . means the current directory.
- .. means the parent directory.

Examples:
Absolute path:
/home/hswkbioinfo/bioinformatics-roadmap/scripts  

Relative path:
scripts
notes/day01.md

Reflection:
Today I learned how to move around my WSL Ubuntu file system without using the mouse. This is important because bioinformatics workflows often require moving between data, scripts, results, and notes folders and it is easier to do via a CLI than a GUI.
