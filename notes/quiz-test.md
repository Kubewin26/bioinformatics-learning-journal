## 🎯 Purpose of Today's Session

After being away from my bioinformatics learning journey for several weeks, I dedicated the last two days (Reactivation Days 1 and 2) to reviewing concepts, reading past notes, and restoring my workspace.

Instead of passively reading through notes, today's objective was to run hands-on exercises in Bash, Git, and GitHub from memory. This drill was designed to test:

- **What is still rusty or uncertain**, identifying the exact gaps I need to revisit.

---

## 💡 The Goal

Bioinformatics is a discipline where tools must become second nature. Through targeted repetition, these drills will:

1. Build sharp muscle memory for command-line file inspection and data manipulation.
2. Reinforce the standard Git version control cycle (`edit` ➔ `status` ➔ `add` ➔ `commit` ➔ `push`).
3. Transition commands, syntax, and workflows from my notes directly to my fingertips.

---

## 🛠️ Drill Log & Observations

### 1. Commands Recalled Smoothly From Memory

These core navigation and inspection commands came back naturally without hesitation:

- **Bash:**
  - `cd` — Directory navigation
  - `mkdir` — Creating new directories
  - `head` & `tail` — Previewing top and bottom lines of files
  - `cat` — Printing file contents
  - `wc` — Word and line counting
  - `cp` — Copying files safely

- **Git:**
  - `git status` — Checking working directory and staging states
  - `git log --oneline` — Compact single-line commit history
  - `git log --oneline --graph` — Visual graph view of commit history and branches
  - `git branch` — Listing existing branches

---

### 2. Commands That Caused Hesitation or Needed a Lookup

Documenting these honestly as my priority drill list:

- **Bash:**
  - `grep` — Struggled with recall and syntax; hesitated on pattern matching and flags (did not look it up yet, keeping it as an active drill target).

- **Git (Branching Workflows):**
  - `git branch <new_branch_name>` — Creating a new branch
  - `git switch <branch_name>` — Switching between active branches
  - `git merge <branch_name>` — Merging branch changes together
  - `git branch -d` / `git branch -D` — Deleting merged vs. unmerged branches

> **Reflection on Gaps:**  
> These Git branching workflows were only rehearsed yesterday during Reactivation Day 2. Because they are so new, they are not second nature yet. Hesitating on them is completely expected at this stage—no shame in acknowledging the gaps. Stating them clearly gives me a focused target for upcoming practice sessions.

## 💭 Key Takeaway Today

Showing up consistently for daily drills—even for short sessions—is what bridges the gap between understanding a concept and being able to execute it effortlessly in a real computational pipeline. The fundamentals (navigation, file reading, basic commits) are now solid; my next frontier is locking down pattern searching with `grep` and fluid branch management.
