# Key Takeaway
- The Secure Shell Protocol (SSH) is used to authenticate access on the command line. One SSH key pair authenticates my entire machine to my entire GitHub account. 
- Every repository I will ever create or clone on GitHub will use the same key automatically. It is like a lab access card where one card gets me through the door of the whole building; I do not need a new card for each room.

- "git remote add origin" is used to connect a local repo to a remote repository, and 'git remote -v' is used to check if the process worked.

- The -u flag in git push -u origin main is used to associate the current branch with a remote branch so that the git pull command can be used without any arguments.  This command will push the changes from our local repository to the repository on GitHub
